# Self Storage

A self-storage facility management app — manage storage units, customers, bookings, and payments.

## Features (roadmap)

- Unit inventory: sizes, prices, availability status
- Customer management: contact info, rental history
- Bookings: move-in / move-out, reservations
- Payments: invoices and payment tracking
- Dashboard: occupancy rate and revenue overview

## Tech stack

- **Frontend:** React (client/)
- **Backend:** Node.js + Express (server/)

## Getting started

```bash
# Backend
cd server
npm install
npm start

# Frontend (in a second terminal)
cd client
npm install
npm run dev
```
